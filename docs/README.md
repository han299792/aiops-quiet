- **처음 본다** → 1 → 2. 여기까지가 이야기 전부다

- **코드를 짜야 한다** → 4 → 3 §3(조건), §4(누출 정의)

## 한 문단 요약

> AIOps 에이전트가 **조용한 장애**를 얼마나 잡는지 재보려고 Microsoft의 AIOpsLab에
> 기여하며(PR #123 머지) 프레임워크를 읽었다. 읽다 보니 **에이전트가 셸로 정답을
> 직접 읽을 수 있다**는 걸 발견했다 — 장애가 configmap 값이나 Chaos CR로 클러스터에
> 남는데 `exec_shell`은 대화형 명령 5개만 막는다. 그래서 질문을 바꿨다:
> **"에이전트가 맞힌 게 추론인가 조회인가."** 이건 답이 정해진 질문이 아니다.
> "할 수 있다"는 코드에서 따라 나오지만 **"실제로 하는가"는 재봐야 안다.**
