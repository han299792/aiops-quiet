# 5. 비용 — 얼마 들고, 어떻게 막나

> 한도: **$32** (₩50,000, 환율 1,400 기준). `--budget` 기본값에 박혀 있다.

---

## 5.1 왜 예상보다 비싼가 — 히스토리 재전송

에이전트 루프는 **매 스텝 대화 전체를 다시 보낸다.** API가 무상태라서다.
그래서 입력 토큰이 스텝 수에 **비례가 아니라 제곱으로** 는다.

```
스텝 1:  시스템 + 지시
스텝 2:  시스템 + 지시 + [행동1 + 응답1]
스텝 3:  시스템 + 지시 + [행동1 + 응답1] + [행동2 + 응답2]
...
스텝 20: 앞의 19턴 전부 + 새 응답
```

20스텝이면 누적 입력이 1+2+...+20 = **210턴어치**다.

## 5.3 ★ 두 종류의 캐시를 헷갈리면 안 된다

이 프로젝트는 캐시 하나는 **끄고** 다른 하나는 **켠다.** 이름이 비슷해서 위험하다.

| | 응답 캐시 (`use_cache`) | 프롬프트 캐시 (`prompt_cache`) |
|---|---|---|
| 무엇 | 같은 메시지 목록 → **디스크에 저장된 답을 그대로 반환** | 서버가 프리픽스의 KV를 캐시 |
| 응답 | **매번 동일** | **매번 새로 생성** |
| 독립성 | **깨진다** | 영향 없음 |
| 비용 | 재호출 0 | 읽기가 입력가의 **0.1배** |
| 설정 | **OFF** (기본) | **ON** (기본) |

응답 캐시를 켜면 같은 문제를 6번 반복해도 1스텝이 항상 캐시 히트라 궤적이 재생된다.
**반복 실험이 재려는 분산이 바로 그렇게 사라진다.** 그래서 껐다.

프롬프트 캐시는 모델이 매번 새로 생성한다. 재전송된 히스토리가 싸질 뿐이다.
**독립성을 건드리지 않으므로 켠다.**

## 5.4 한도가 실제로 작동하는 방식

숫자를 적어두는 것만으로는 한도가 아니다. 세 지점에서 강제한다.

| 언제 | 무엇 |
|---|---|
| **회차 시작 전** | `preflight()` — 남은 예산 < 1회분이면 시작을 거부하고 캠페인을 멈춘다 |
| **스텝마다** | `check()` — 상한을 이미 넘었으면 회차 중단 |
| **호출 직후** | `charge()` — 원장에 **원자적으로 기록**. 중간에 죽어도 회계가 안 날아간다 |

1회분 예약분은 처음엔 $1.5로 두고, **이력이 쌓이면 실측 평균으로 바뀐다.**
추정이 아니라 이 캠페인에서 실제로 든 값으로 판단한다.

> 사후에 아는 건 늦다. 이전 프로젝트에서 $5.89 추정이 $40.18이 된 적이 있고,
> 그때는 다 쓰고 나서야 알았다.

## 5.5 예상이 틀리면

파일럿(5문제 × 1회)에서 **실측**한다. 그다음:

| 파일럿 결과 | 조치 |
|---|---|
| 회차당 ≤ $0.5 | 그대로 60회 진행 |
| $0.5 ~ $1.0 | `--max-steps`를 20 → 12로. 비용이 제곱으로 줄어든다 |
| > $1.0 | **N이 아니라 문제 수를 줄인다.** 조건당 반복이 통계의 근거다 |
| 캐시 미적중 | `cache_read_tokens`가 0인지 확인. 설정했다고 되는 게 아니다 |

마지막 줄이 중요하다. `usage`가 `cache_read_tokens`를 따로 기록하므로
**캐시가 실제로 맞았는지 회차마다 눈으로 확인**한다.

## 5.7 재현

```bash
python - <<'EOF'
def cost(steps, sys_tok, act_tok, env_tok, p_in, p_out, cache_read=None):
    inp = out = cached = 0
    for k in range(1, steps + 1):
        prefix = sys_tok + (k - 1) * (act_tok + env_tok)
        if cache_read is None:
            inp += prefix + env_tok
        else:
            cached += prefix; inp += env_tok
        out += act_tok
    return (inp * p_in + out * p_out + cached * (cache_read or 0)) / 1e6

print(cost(20, 1500, 200, 2000, 5.0, 25.0))            # 캐시 없음
print(cost(20, 1500, 200, 2000, 5.0, 25.0, 0.5))       # 캐시 있음
EOF
```

단가는 `quiet/harness/pricing.json`에 있고 버전이 원장 항목마다 박힌다.
